# Student Study Planner

A responsive study planner built with HTML, CSS and JavaScript.

## Features

- 📚 Subject dashboard
- 📝 Add and delete study tasks
- ✅ Mark tasks as completed
- 📊 Automatic study progress percentage
- 📈 Progress bar
- ⏱️ 25-minute study timer
- 🌙 Dark mode
- 💾 LocalStorage for saving tasks
- 📱 Mobile responsive design

## Technologies Used

- HTML
- CSS
- JavaScript

## Project Purpose

This project was created to practice front-end web development and build a simple tool for managing daily study activities.
